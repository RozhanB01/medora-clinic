# Medora Clinic

A modern medical clinic website concept designed as a professional portfolio project.

## Overview

Medora Clinic is a fictional healthcare website created to demonstrate modern web design and front-end development skills.

The project focuses on:

- Clean medical UI
- Responsive design
- Mobile navigation
- Appointment form
- Service sections
- Doctor profiles
- Contact section
- Modern typography
- Responsive layouts

## Technologies

- HTML5
- CSS3
- JavaScript
- Google Fonts

## Features

### Responsive Design

The website works on:

- Desktop
- Tablet
- Mobile

### Appointment Form

Users can select:

- Their name
- Email
- Medical service
- Preferred date

### Mobile Navigation

The navigation automatically transforms into a mobile menu on smaller screens.
