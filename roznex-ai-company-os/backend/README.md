# NOVEMBER LINE — Gateway آزمایشی هوش مصنوعی

این بخش یک **سرویس واقعی گفت‌وگوی هوش مصنوعی** است، نه عامل خودکار کدنویسی. کلید سرویس فقط روی سرور می‌ماند و به مرورگر ارسال نمی‌شود.

## نصب و اجرا

- Node.js نسخه 20 یا بالاتر
- تنظیم متغیرهای محیطی `OPENAI_API_KEY`، `NL_ALLOWED_ORIGIN` (آدرس کامل سایت مانند `https://example.com`) و `PORT` (اختیاری)
- اجرا از پوشه مخزن: `node roznex-ai-company-os/backend/server.cjs`
- سلامت سرویس: `GET /health`
- گفت‌وگو: `POST /api/chat` با بدنه `{"agent":"NEX","message":"سلام","project":{"name":"NOVEMBER LINE"}}`

برای اتصال وب‌اپ، مقدار `window.NOVEMBER_LINE_API_BASE` را **پیش از اجرای کد اصلی صفحه** روی آدرس HTTPS این سرویس تنظیم کنید. سرویس فاقد پایگاه داده و احراز هویت کاربران است؛ به‌هیچ‌وجه آن را به‌عنوان endpoint مدیریتی محرمانه یا محیط چندکاربره آماده تولید در نظر نگیرید.

## محدودیت‌ها و امنیت
- CORS فقط مبدأ `NL_ALLOWED_ORIGIN` را قبول می‌کند؛ CORS ابزار احراز هویت نیست. نرخ‌دهی بر اساس IP صرفاً حداقلی است و برای اینترنت عمومی کافی نیست.
- اجرای ابزار، تغییر مخزن، commit، PR، پرداخت، انتشار و دسترسی به فایل‌ها **از طریق این سرویس امکان‌پذیر نیست**.
- سرویس برای استفاده خصوصی/آزمایشی طراحی شده است. پیش از انتشار عمومی، احراز هویت، سیاست مصرف و هزینه، ذخیره‌سازی مناسب، محدودسازی درخواست در لبه و ثبت رخدادهای امنیتی باید اضافه شوند.
- پاسخ‌های محلی در نبود سرور شبیه‌سازی هستند و نباید با نتیجه اجرای واقعی اشتباه گرفته شوند.

## تست سریع
`node --check roznex-ai-company-os/backend/server.cjs`

## تست و استقرار آزمایشی

برای اجرای تست‌ها: `node --test roznex-ai-company-os/backend/server.test.cjs`.

فایل `render.yaml` در ریشه مخزن یک Blueprint اختیاری Render است. مقدار `OPENAI_API_KEY` و `NL_ALLOWED_ORIGIN` باید به‌صورت محرمانه از پنل Render تنظیم شود. صرف وجود فایل، سرویس را راه‌اندازی نمی‌کند. همچنین آدرس بک‌اند باید در پیکربندی فرانت‌اند `window.NOVEMBER_LINE_API_BASE` پیش از بارگذاری برنامه قرار گیرد. برای استفاده عمومی، احراز هویت و محدودیت مصرف مستقل الزامی است.
